# Chrome Web Store listing copy

## English (default)

**Name**  
Jiddu — Critical Reading

**Summary**  
Select a passage on any page and analyze fallacies, factual claims, or bias with Jiddu.

**Detailed description**

Read the web with a second, critical perspective beside the original page.

Jiddu lets you deliberately select a passage on a website and choose one of three focused lenses:

- Fallacies — inspect the structure of the reasoning and identify possible logical fallacies.
- Facts — check verifiable claims and review cited sources.
- Bias — surface framing, attribution, omissions, and other patterns that may shape interpretation.

How it works:

1. Click the Jiddu icon or use its keyboard shortcut.
2. Select the passage you want to examine.
3. Choose Fallacies, Facts, or Bias.
4. Read the result in a side panel tied to the original tab.

You can choose English, Portuguese, or Spanish independently for the interface and the explanations. Completed analyses can be printed as clean reports.

Jiddu activates only after an explicit user action. Hovering over or selecting a passage does not send it anywhere. The selected passage is transmitted over HTTPS only after you choose an analysis. A Jiddu account and personal API key are required.

Automated analyses can be wrong and should be used as reading aids, not final judgments. Review the explanation and open cited fact-check sources.

## Português (Brasil)

**Nome**  
Jiddu — Leitura crítica

**Resumo**  
Selecione um trecho em qualquer página e analise falácias, afirmações factuais ou parcialidade com o Jiddu.

**Descrição detalhada**

Leia a web com uma segunda perspectiva crítica ao lado da página original.

O Jiddu permite selecionar deliberadamente um trecho e escolher uma de três lentes:

- Falácias — examine a estrutura do raciocínio e identifique possíveis falácias lógicas.
- Fatos — cheque afirmações verificáveis e consulte as fontes citadas.
- Parcialidade — revele enquadramentos, atribuições, omissões e outros padrões que podem influenciar a interpretação.

Como funciona:

1. Clique no ícone do Jiddu ou use o atalho do teclado.
2. Selecione o trecho que deseja examinar.
3. Escolha Falácias, Fatos ou Parcialidade.
4. Leia o resultado em uma side panel vinculada à aba original.

É possível escolher inglês, português ou espanhol separadamente para a interface e as explicações. Análises concluídas podem ser impressas como relatórios limpos.

O Jiddu só é ativado após uma ação explícita. Passar o cursor ou selecionar um trecho não envia nada. O texto selecionado só é transmitido por HTTPS depois da escolha de uma análise. É necessário ter uma conta Jiddu e uma chave pessoal de API.

Análises automatizadas podem errar e devem ser usadas como auxílio à leitura, não como julgamentos finais. Revise a explicação e abra as fontes citadas nas checagens de fatos.
